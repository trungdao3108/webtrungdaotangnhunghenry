# Birthday Landing Page

Project Vite + React + TypeScript + Tailwind CSS.

## Cai dat

```bash
npm install
npm run dev
```

## Kiem tra TypeScript

```bash
npm run typecheck
```

Luu y: project da bo sung `typescript`, `@types/react`, `@types/react-dom` va `tsconfig.json` de VS Code nhan dung JSX `key` va cac type cua React.
